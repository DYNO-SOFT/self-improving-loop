# self-improving-loop

Self-improvement loop + cognitive-error guardrails. Loaded as plugin context.

- Before finalizing any session with real work, run the self-improve skill:
  audit for cognitive errors, then capture durable lessons.
- Durable fact -> memory (`~/.claude/LEARNED.md` machine, `<repo>/AGENTS.md` project).
- Repeatable procedure -> a skill.
- `Verified:` means the command ran and the exit code was checked.
